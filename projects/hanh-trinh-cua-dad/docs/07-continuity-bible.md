# 07 — Continuity Bible

## Dad

**Canonical identity:** real Dad as represented by project-approved photo/video references.

### MUST remain stable
- facial identity;
- characteristic hair/facial-hair state for each real-life period;
- skin tone;
- glasses/accessories if period-specific;
- wardrobe within one sequence.

### Period rule

Do not infer a younger version from a present-day face and present it as documentary truth.

If younger-Dad photos exist:
- use those actual images as reference.

If not:
- use stylized silhouette/cutout/graphic representation.

## Comedy vs documentary visual states

### COMEDY_MYTH
- paper collage;
- poster/game graphics;
- exaggerated captions;
- Dad may appear as photo cutout;
- kangaroo/buffalo are clearly theatrical.

### DOCUMENTARY_REAL
- actual photos/footage;
- restrained parallax;
- clean captions;
- no fabricated event imagery.

The film must never drift between these states ambiguously.

## Australia/Vietnam geography

Map graphics must keep:
- Australia and Vietnam geographically recognizable;
- route direction Australia → Vietnam;
- no false precise city labels until verified.

## Website

Use actual captured site visuals.

Do not fabricate page text, logo, navigation, or testimonials.

## Transition continuity

- S01_SH04 → S01_SH05: kangaroo comedy exits into map movement.

Once a verified date/place is introduced, every later caption/map/timeline must use the same value.
