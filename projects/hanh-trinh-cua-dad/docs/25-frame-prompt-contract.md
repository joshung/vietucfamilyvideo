# 25 — Exact Per-Frame Prompt Contract — LEGACY V1

> **SUPERSEDED.** V2 per-frame authority is `production/vox-v2/frame-manifest.jsonl`.

The canonical machine-readable frame prompt file is:

`production/remotion/frame-prompt-manifest.jsonl`

It contains exactly 2880 records, one for every master frame `F0000` through `F2879` at 24fps.

It is generated by:

`scripts/build-frame-prompt-manifest.mjs`

The generator parses the complete action ranges from `docs/22-frame-by-frame-paper-stop-motion.md`, checks that every frame is covered once and only once, joins each frame with its scene hero prompt, computes action-range progress and stepped paper-pose frame, and writes an exact expanded compositor prompt.

This is **not** an instruction to call an image model 2880 times. The master is deterministic Remotion. A frame prompt describes the exact compositor state that the rendered frame must satisfy. Only asset IDs explicitly listed in `production/remotion/image-generation-manifest.json` may be generated by an image model.

Each row includes: global frame, 24fps timecode, scene ID, component, local frame, active action range, current action, progress, cadence, stepped pose frame, hero-frame target, generation policy, reference assets, prompt ID, expanded exact prompt, and non-negotiable invariants.

Cadence interpretation: `STEP2` changes paper transforms on even frames and repeats the prior pose on odd frames; `STEP3` changes every third frame; `SMOOTH` uses raw 24fps interpolation; mixed ranges keep paper stepped while documented camera/crop motion remains smooth. Unmarked active paper movement defaults to STEP2; explicit holds remain holds.

Whenever the frame blueprint changes, run:

```bash
node scripts/build-frame-prompt-manifest.mjs
```

The command must fail on a gap, overlap, scene-range mismatch, missing hero prompt, or any output count other than 2880.
