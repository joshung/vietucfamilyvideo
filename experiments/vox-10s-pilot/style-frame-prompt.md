# Pilot Style Frame Prompt

## Use

Create **one still style frame first**.

Do not animate until this frame is approved.

## Attach

- DAD_REF_01 as the real Dad source;
- optional paper texture reference from existing project;
- accurate Australia SVG is supplied separately to the compositor.

## Prompt

```
Create a premium modern editorial-documentary paper-collage style frame for a 16:9 explainer.

The real Dad Stevenson photo reference must remain unchanged and recognizable as a physical photo cutout. Place Dad on the right half of a warm cream archival-paper canvas with subtle visible paper fibers and a soft down-right drop shadow.

Behind Dad, leave space for an accurate Australia map to be composited separately. The map itself must NOT be invented by the image model.

On the left, reserve a clean strong editorial text area for the title “DAD STEVENSON” and a small location label “ADELAIDE — SOUTH AUSTRALIA”, but do not render any text into the generated image.

Visual language: sophisticated explanatory journalism, physical construction paper, cut-photo collage, muted cream/charcoal/gray palette with one highlighter-yellow accent, restrained halftone print texture, subtle analog imperfection, soft studio light from upper-left, editorial rather than advertising, handmade but precise, tactile paper depth.

The composition must feel calm, intelligent and intentionally designed. One visual idea only. No clutter, no glossy CGI, no corporate 3D icons, no futuristic interface, no random data graphics, no flags, no American imagery, no United States map, no USA landmarks, no generated words, no logos, no watermark.

Do not beautify, redraw, de-age, stylize or alter Dad’s face. Dad is a real photo layer, not an AI character.
```

## Acceptance

Approve only if:
- Dad remains clearly the same person as DAD_REF_01;
- frame feels editorial rather than advertising;
- paper material looks physical;
- there is enough negative space for title/map labels;
- no US/America imagery appears;
- palette can be reproduced scene-to-scene.
